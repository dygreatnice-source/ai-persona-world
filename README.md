# AI PERSONA WORLD

회천중학교 AI 디지털 융합 체험 수업(2026.11.24) **「AI PERSONA WORLD — 나를 대신할 AI 페르소나 만들기」** 학생용 웹앱입니다.

- `index.html` 하나로 동작하는 순수 HTML/CSS/JS (빌드·서버·API 없음)
- 스마트기기 세로 화면(360~430px) 최적화
- 모든 선택 데이터는 학생 기기 브라우저(localStorage)에만 저장됩니다.

## 사용 방법
1. 학생 스마트기기에서 아래 주소를 열거나 QR 코드를 찍습니다.
2. 닉네임만 입력하고 시작합니다. (실명·학번 사용 안 함)
3. MISSION 01 → 02 → 분석 → 03 → 04 → 발표 카드 순서로 진행합니다.
4. 2차시에는 MISSION 04(월드 체험)와 카드 발표를 합니다.
